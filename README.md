# HELLDIVERS // COMMAND CENTER

Личный дашборд для статистики Helldivers 2: закинул два скриншота, получил графики.

---

## О проекте

Сайт для отслеживания личной статистики в Helldivers 2. Поскольку игра не предоставляет публичный API с данными игроков, статистика импортируется через скриншоты раздела «Арсенал → Карьера».

Сайт автоматически распознаёт показатели, сохраняет их и позволяет отслеживать динамику K/D, точности, успешности миссий и других параметров.

Распознавание оптимизировано только под русскую версию игры на данный момент.

## Как это работает

1. Загружаешь два скриншота экрана «Карьера» (весь список на один не влезает).
2. OCR распознаёт текст прямо в браузере.
3. Сайт склеивает значения с обоих скриншотов и проверяет их на согласованность.
4. Ты смотришь результат и правишь то, что распозналось спорно.
5. Снимок статистики сохраняется локально.
6. Обзор и аналитика обновляются.

## Что умеет

- Импорт из двух скриншотов: drag-and-drop, выбор файла или вставка из буфера.
- Обзор карьеры: все 24 показателя, K/D, успешность, точность и изменения с прошлого снимка.
- Аналитика: боевой портрет (Combat Intelligence), графики динамики, соотношения, убийства по фракциям, сравнение снимков, рекорды между снимками.
- Галактическая война: актуальные главные приказы с прогрессом и таймером (данные из [Helldivers 2 Community API](https://github.com/helldivers-2/api)).
- История снимков: просмотр, сравнение, удаление, отметка сброса статистики.
- Экспорт и импорт JSON.

## Где лежат данные

Личная статистика хранится в IndexedDB твоего браузера, без аккаунта. Скриншоты никуда не отправляются. Данные привязаны к конкретному браузеру, поэтому время от времени скачивай резервную копию в JSON на странице «Данные».

Сервер нужен только для страницы «Галактическая война»: он запрашивает приказы у Community API и коротко кэширует ответ, чтобы не превышать лимит запросов. Личные данные на сервер не попадают.

Необязательная переменная окружения `HD2_API_CONTACT` задаёт контакт, который передаётся в Community API (по умолчанию ссылка на этот репозиторий).
